# Аудит бизнес-приложения, 26 ноября 2026

Поток DR, пункт 30 «Очереди Codex». Проверены 28 экранов Expo-приложения для владельца, администратора и мастера. Двойная отправка затрагивает в том числе создание визита и ручное начисление бонусов. Если подтвердить форму дважды до обновления кнопки, из браузера уходят два одинаковых запроса. Проверка измеряла отправки приложения. Фактическое удвоение записей или баланса в базе не установлено.

## Условия

- Сборка Expo Web из ветки `codex/dr-audit-business`. Размер окна Chromium 320 × 740 CSS px. Увеличение текста до 130 % проверяется по вычисленному размеру шрифта. На выбранных подписях проверяются границы отрисованных слов.
- PL, EN, UA и RU. Для украинского языка используется код `uk`, в переключателе показывается UA. Для каждого языка открывали экраны, доступные выбранной роли. До выбора салона роль ещё не определена. Для мастера отдельно проверялись скрытые пункты меню и действия, требующие дополнительного права.
- Пустые состояния задавались успешными ответами с пустыми данными. Обрыв воспроизводился на чтении или записи. При проверке медленной сети ответ удерживался до нажатия и проверки состояния кнопки. Для повторной отправки проверялись как обычный двойной щелчок, так и два вызова кнопки подряд до перерисовки формы.
- Данные для матрицы ролей подготовлены в Playwright. Все переходы выполнялись через интерфейс собранного приложения. Касса, склад, карточки и календарь дополнительно проверялись существующими сценариями, в том числе с локальным API и PostgreSQL. Системный шрифт, клавиатура и окно «Поделиться» на физических устройствах iOS и Android в этот прогон не входили.
- Списки изменённых файлов сверены по всем страницам PR #19, #20 и #127–#134. В таблице «после вливания» указаны PR, после которых нужно повторить проверку на `main`. Для пути в колонке «Файл» корень — `apps/mobile-business/src/`.

При дополнительном обходе 29 путей для всех 12 сочетаний роли и языка браузер сначала открывал календарь с сетью, затем отключал соединение перед входом в выбранный раздел. Из 264 открытий и обновлений без сети 248 требовали данных сервера. Во всех 248 появилось сообщение на выбранном языке. Форма блокировки открывалась локально у всех ролей, форма проверки сертификата — у мастера. Ещё 72 пункта были скрыты для соответствующей роли. Отдельно проверены 12 выходов с задержанным ответом. На экранах «День» и «Ещё» в 24 представлениях все 1194 измеренных слова поместились по ширине.

## Как повторить проверки

Новый набор содержит 92 браузерных случая в шести файлах. Для локального воспроизведения сначала собрать браузерную версию приложения. Из корня репозитория выполнить команды с установленными зависимостями и Chromium Playwright.

```sh
pnpm --filter @beauty/mobile-business exec expo export --platform web --output-dir dist
pnpm --filter @beauty/mobile-business test
pnpm --filter @beauty/mobile-client test
pnpm typecheck
pnpm --filter @beauty/web exec playwright test 'app-audit-business-.*\.spec\.ts' --repeat-each=5 --retries=0
```

В `apps/mobile-business/test/audit-*.test.ts` проверяются восстановление сеанса, время визита при переводе часов, скидки и стоимость наград, видимость членов команды и перевод журнала. В `apps/web/e2e/app-audit-business-*.spec.ts` сценарии сгруппированы по календарю, клиентам, настройкам, торговле, доступу и восстановлению сеанса.
