Медленные ответы удерживались до контрольной точки в интерфейсе. Для проверки отдельных разделов Playwright обрывал выбранный запрос. Для прямой ссылки на запись выключалась сеть всего браузерного контекста: Chromium вернул `ERR_INTERNET_DISCONNECTED`, после восстановления связи повтор ушёл с тем же ключом идемпотентности и открыл контакты. API, данные визитов и плитки карты в новых сценариях контролируются тестами. Нативные окна календаря, камера, системная выдача разрешений и запуск ссылки операционной системой на физических iOS/Android остаются за пределами этой проверки.

Отдельные диагностические прогоны на английском подтвердили три проблемы салона и истории просмотров (возврат, запоздалое пополнение истории, доступная запись без услуг), исчезновение купонов и потерю товаров при повторной записи. Основные маршруты этих экранов входят в четырёхъязычную проверку.

## Как повторить проверки

```sh
pnpm --filter @beauty/mobile-client test
pnpm --filter @beauty/mobile-business test
pnpm typecheck
pnpm --filter @beauty/mobile-client exec expo export --platform web --output-dir dist
pnpm --filter @beauty/web exec playwright test 'app-audit-client-.*\.spec\.ts' --repeat-each=5
```

Модульные файлы `apps/mobile-client/test/audit-*.test.ts` проверяют сроки геолокации, сохранённую сессию и имена параметров в переводах. Браузерные файлы `apps/web/e2e/app-audit-client-*.spec.ts` открывают собранное приложение и проверяют видимый результат вместе с количеством и содержимым запросов.
