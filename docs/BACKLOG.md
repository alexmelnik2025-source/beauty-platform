# Очередь задач агента-разработчика

Агент «Разработка приложения» (задача по расписанию) берёт **первую незакрытую** задачу сверху,
делает её на отдельной ветке, проверяет в CI и переносит в `main`. Владелец может переставлять,
добавлять и вычёркивать задачи — порядок здесь главный. Цель: к марту 2027 запись и приложения готовы,
апрель — тест, открытие нового барбершопа ≈ конец апреля 2027 (план: https://claude.ai/artifact/QbqGrxf1uWw4u9nFmM3c9a).

Правила для каждой задачи: тесты на настоящей PostgreSQL, 4 языка (PL/UA/RU/EN), права и изоляция салонов
проверяются на сервере, никаких платных сервисов, секретов в репозитории и выкладки на серверы.

(агент пишет сюда вопросы, без ответа на которые задачу не сделать, и переходит к следующей задаче)

- **Бонусы:** ответ владельца получен 02.11.2026 — `docs/LOYALTY_SPEC.md` (салон настраивает всё сам).
  Финансовая модель (владелец, 02.11.2026): **скидку по программе лояльности оплачивает заведение** — салон сам
  идёт на это, чтобы привлечь клиента; платформа скидку не компенсирует. Учитывать в 10d (скидка уменьшает цену
  визита салона) и в 10g (при общих баллах скидку оплачивает салон, который её даёт/начислил — детали вариантами).

- **SMS-шлюз (платно).** Код по SMS готов в коде, но настоящие SMS не уходят — нужен польский SMS-шлюз.
  Варианты: SMSAPI.pl, SerwerSMS.pl, Twilio; цену за одно SMS владелец смотрит
  у выбранного шлюза. До решения на рабочем сервере клиенты видят только код по email.
